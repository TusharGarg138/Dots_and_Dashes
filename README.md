🎯 Features:
✅ Converts plain English text to Morse code

✅ Converts Morse code back to English text

✅ Simple and clean Graphical User Interface (GUI)

✅ Dark mode UI with stylish buttons and fonts

✅ Real-time output display




🛠️ Tech Stack:
Python (Core logic)

Tkinter (GUI development)



🚀 How It Works:
Type your message in the input box.

Click "Encrypt" to get Morse code.

Click "Decrypt" to convert Morse code back to text.

Output appears in the box below.
